# Cascade Solar + Air - Finance Operations

An interactive, single-page prototype of a finance-operations console for a
residential solar and HVAC services company. It is a self-contained static web
app with no build step and nothing to install.

## Live demo

Once GitHub Pages is enabled for this repository, the site is published at the
URL shown under Settings, then Pages (GitHub prints "Your site is live at ..."):

```
https://kadeemhaughton.github.io/Solar-HVAC/
```

## What's here

- `index.html` is the complete prototype, with all styles and scripts inline.
- Light and dark themes, with a toggle that remembers your choice per browser.
- Responsive layout that works on phones, tablets, and desktops.
- Web fonts (Inter, Sora, IBM Plex Mono) loaded from Google Fonts.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

## Running it locally

There is no build step and nothing to install. Open `index.html` directly in a
browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
